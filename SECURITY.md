# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

The Code2Larp team takes security seriously. If you discover a security vulnerability or sensitive data leak (such as exposed API credentials), please report it responsibly:

1. **Do not** create a public GitHub issue for security vulnerabilities.
2. Email the details to `adrianxavier0213@gmail.com`.
3. Include a description of the vulnerability, steps to reproduce, and any potential remediation.

We appreciate your effort in helping keep our project safe!
